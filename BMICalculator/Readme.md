# BMI Calculator

## Description
A simple Python-based BMI Calculator that calculates Body Mass Index (BMI) based on the user's weight and height.

## Features
- Takes weight in kilograms (kg)
- Takes height in meters (m)
- Calculates BMI
- Classifies BMI as Underweight, Normal, Overweight, or Obese
- Validates invalid and negative inputs
- Displays BMI rounded to 2 decimal places

## Formula
BMI = Weight (kg) / Height² (m)

## Technologies Used
- Python

## How to Run
1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Run the `bmi_calculator.py` file.
4. Enter your weight and height when prompted.
5. The BMI result and category will be displayed.
