# Basic Weather App

## Description
A simple Python application that displays real-time weather information for a user-entered city.

## Features
- Accepts city name as input
- Displays temperature in Celsius and Fahrenheit
- Displays humidity
- Displays weather condition
- Displays wind speed
- Handles invalid city names and network errors

## Technologies Used
- Python
- requests library

## How to Run
1. Install Python.
2. Install the requests library using:
   pip install requests
3. Run the `weather_app.py` file.
4. Enter a city name.
5. View the weather details.
