# Random Password Generator

## Description
A simple Python program that generates strong random passwords based on user preferences.

## Features
- User can choose password length
- Supports uppercase letters
- Supports lowercase letters
- Supports numbers
- Supports symbols
- Generates a random password
- Option to generate another password
- Handles invalid input

## Technologies Used
- Python
- random module
- string module

## How to Run
1. Install Python.
2. Open the project in VS Code.
3. Run the `password_generator.py` file.
4. Enter the password length.
5. Choose the character types.
6. The program generates a random password.
